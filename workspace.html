{% elif section == "about" %}
CAMPUS CATALYST · PROJECT 118

Nature, measured
with curiosity.

Flower Measurement Explorer is a local-first learning application for visualizing flower measurements and exploring class patterns before classification.

Explore observations →
THE OBSERVATION

Four simple measurements

Sepal length and width, petal length and width are recorded in centimeters with explicit, domain-aware bounds.

THE EXPLORATION

Patterns, not assumptions

Interactive charts, descriptive summaries, K-means clustering, PCA, and outlier review make patterns visible without automatically assigning a species.

THE PROMISE

Your work stays local

Accounts and observations are stored in SQLite on this machine. The included 150-measurement Fisher Iris dataset is from the UCI Machine Learning Repository. CSV and JSON provide transparent import and export formats.
